HOW TO RUN
1. Open this project folder in VS Code.
2. Open the VS Code terminal in this folder.
3. Run:
   pythonw .\Quiz.py
4. If pythonw does not work, try:
   pyw .\Quiz.py

A desktop quiz window will open. Enter your name and use the on-screen
buttons to answer the questions. No third-party packages are required;
the application uses Python's built-in Tkinter library. The pythonw
command opens the window without displaying a terminal.

FILES
- Quiz.py           : quiz application and graphical user interface
- quiz_results.txt  : quiz results, appended after each completed quiz
- Project_Report.txt: project report
- README.txt        : project instructions
